# UV candidate experiments (exploratory scripts)

Standalone numpy/scipy/sympy scripts behind docs/UV_CANDIDATE_ASSESSMENT.md. Run each with `python <script>.py`.
Exception: `scalar_mediator_dynamicU_check.py` needs the B4.10 package (`b410`) and `data/e3_manifest.json`; run it from the B4.10 directory.
These are exploratory (fixed seeds, no unit tests). Verdicts hold only for the stated constructions and samples.
