# Lambda: sectors, symbols and phase prescriptions

Purpose: one place that fixes which "Lambda" is meant, in which units, and which phase prescription is used. Created after two quantities with the same
name were conflated (2026-11-12, see the correction in T63_FOLIATION_AND_KZ.md).

## Decision (project lead, 2026-11-13)
The primary observational sector of B4-BEC-Lambda-Bridge is the GRAVITON sector (gravitational waves): Lambda_GW and Delta Psi_GW(f).
The photon sector of Paper II (photon ring, shadow, chromaticity) is a separate application, connected only through a future common UV theory.
Lambda_GW and Lambda_gamma are NOT identified. Their relation (equal, different, or a fixed ratio) is something a concrete UV theory must predict; sector
independence is an admissible hypothesis to be justified under T7, not a free parameter for avoiding the photon bound.
T8 is split: T8-GW (graviton dispersion and phase correction) and T8-gamma (photon observables of Paper II). They are not merged before T7.
This decision changes no existing GWTC-4.0 bound and no matched-filter code.

## Symbols
| Symbol | Meaning | Units |
|---|---|---|
| Lambda_B4 | coefficient of the operator (Lambda/4) phi_x^4 in the B4 EFT (nonlinear, second order in derivatives; produces no dispersion) | 1/(d phi)^2, per the B4 normalisation |
| beta_i | coefficient of k^3 in omega = c0_i k + beta_i k^3 for mode i; generated by the mediator (beta ~ 1/M^2), not by Lambda_B4 | m^3/s (dimensionless in B4 units) |
| Lambda_eff,i = 2 beta_i / c0_i | mode- and frame-dependent effective quantity; undefined at c0 = 0 | m^2 |
| Lambda_physical | coefficient in the local law omega = c k sqrt(1 + Lambda k^2); equals hbar^2 c^2 A_4 | m^2 |
| Lambda_code = c * Lambda_physical | parameter of the matched-filter code (waveform.py, convention_check.py); equals hbar^2 c^3 A_4 | m^3/s |
| Lambda_GW | Lambda_physical for gravitons | m^2 |
| Lambda_gamma | Lambda_physical for photons | m^2 |
Lambda_B4 and Lambda_physical are different quantities. A UV model that reproduced B4 exactly would still not fix Lambda_GW.

## Two phase prescriptions for the k^4 (alpha = 4) dispersion
They differ by the factor (1 - alpha) = -3, in size and in sign. They are different recipes, not two sign conventions, and are not interchangeable.
K_old = Int_0^z (1+z')^2/H(z') dz' [s];  I_4 = c K_old [m];  Lambda = Lambda_physical [m^2];  Fourier convention h~(f) = A exp(+i Psi), Psi_GR containing +2 pi f t_c.

| | (P) particle velocity | (G) group velocity |
|---|---|---|
| velocity | v = p c^2/E = c (1 - Lambda k^2/2) | v = d omega/dk = c (1 + 3 Lambda k^2/2) |
| time shift | Delta t = +(Lambda/2c^2) omega^2 K_old | Delta t = -(3 Lambda/2c^2) omega^2 K_old |
| phase | Delta Psi = +(4 pi^3/3) Lambda I_4 f^3/c^3 | Delta Psi = -4 pi^3 Lambda I_4 f^3/c^3 |
| used by | LVK up to GWTC-3, Mirshekari-Yunes-Will, built-in LIV term of LALSimulation (per phase_convention_check.py) | LVK from GWTC-4.0; waveform.py; this project |
The phase follows from the time shift through d(Delta Psi)/df = 2 pi Delta t, not through Delta Psi = 2 pi f Delta t.

Equivalent forms of (G):
- Lambda in m^2, I_4 in m:      Delta Psi = -4 pi^3 Lambda_physical I_4 f^3 / c^3     (phase_convention_check.py, T63_FOLIATION_AND_KZ.md)
- Lambda in m^3/s, K in s:      Delta Psi = -4 pi^3 Lambda_code K_old f^3 / c^3       (waveform.py)
- LVK form (as transcribed in convention_check.py from arXiv:2603.19020): Delta Psi = -pi D_4 h^2 (1+z)^3 A_4 f^3 / c, D_4 = c K_old/(1+z)^3,
  i.e. -pi h^2 A_4 K_old f^3. With Lambda_code = hbar^2 c^3 A_4 and hbar = h/2 pi this is identical to the line above (checked analytically here;
  convention_check.py reports ratio 1.0000 numerically). The transcription from the LVK source was not checked in this analysis.

Legacy time-domain scripts (gwosc_chirp_dispersion_test.py, gwosc_injection_recovery_test.py) use Delta T = -(Lambda_code/2c^3) omega^2 K_old:
the magnitude of (P) with the sign of (G). This matches neither prescription; numbers from those scripts must not be compared with matched-filter values.

## Bounds, as recorded in the Lambda-model repository (provenance, not re-verified here)
- Graviton sector: GWTC-4.0 modified-dispersion analysis, A_4 in [-620, +190] eV^-2 (90 %), converted with Lambda_physical = hbar^2 c^2 A_4:
  Lambda_GW in [-2.41e-11, +7.40e-12] m^2 (Lambda_code in [-7.24e-3, +2.22e-3] m^3/s). The arithmetic of the conversion was re-checked here.
  This is a conversion of a published external interval, not an independent measurement by this project, and not a confirmation of the model.
  The number of events (83) is as recorded in convention_check.py; not verified against the LVK paper.
- Photon sector: Lambda_gamma <~ 1e-53 m^2 from Fermi-LAT gamma-ray-burst timing (Paper I, as recorded in convention_check.py).
  Order-of-magnitude cross-check: E_QG,2 ~ 1e11 GeV gives (hbar c/E_QG)^2 ~ 1e-54..1e-53 m^2 (value of E_QG,2 recalled from the literature, to be confirmed,
  including the bound for the superluminal sign). The mapping is Lambda_gamma = -s (hbar c/E_QG)^2 for E^2 = p^2 c^2 [1 - s (E/E_QG)^2].
- The ~41 orders between the two bounds reflect the E^2 D scaling of the effect (GeV photons vs ~1e-12 eV gravitons), not a contradiction.
  Consequence: an observable GW effect near current sensitivity requires Lambda_GW >> Lambda_gamma; none of the UV candidates tested so far produces
  a sector dependence (phi, psi are not identified with photon and graviton).
