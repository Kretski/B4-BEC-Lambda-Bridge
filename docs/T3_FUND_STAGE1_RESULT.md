## C0, C1, C2 (analytic; my derivation, to be reviewed)
**C0.** Scalar mediator: constant sigma_bar = (g_phi w q + g_psi v r)/M^2 and linear phi0, psi0 solve the full equations exactly (all derivative terms of sigma and phi_tx vanish). HeavyScalar: chi_bar = g (w^2 - q^2)/M^2 and phi0 = w t + q x solve the full equations exactly (d_mu[(1+2 g chi_bar) d^mu phi0] = 0). C0 holds [ANALYTIC] for every background.

**C2 (full first-order form: U = (a, a_t, a_x) for each field, i.e. 9 variables for the Scalar mediator and 6 for HeavyScalar; U_t + A U_x = B U).** The amplitude rows have no x-derivative (a_t = a_t is a zero-order relation), so A has a zero row and column for every amplitude and keeps the blocks [[2 g_i sigma_bar, -1], [-1, 0]] for phi, psi and [[0, -1], [-1, 0]] for sigma (Scalar mediator), and two blocks [[0,-1],[-1,0]] for HeavyScalar after dividing the phi-equation by Z = 1 + 2 g chi_bar (needs Z != 0). A is real symmetric in every case (also in the full form: the zero rows and columns do not break the symmetry), therefore it has real eigenvalues and a complete orthogonal set of eigenvectors, the amplitude directions being eigenvectors of the eigenvalue 0 (3 zero eigenvalues for the Scalar mediator, 2 for HeavyScalar); condition number of the eigenvector matrix at most 1.0000000000000004 on all 794 backgrounds. The reduction was checked against det K: max Re eig(-ikA + B) agrees with gamma(k) from the characteristic polynomial (differences <= 1e-6 for k <= 1e3 on all sets except A1; on A1 the double-precision polynomial roots are inaccurate because of the triple root c = +-1 at sigma_bar = 0, the first-order eigenvalues give max gamma 7e-10, consistent with the 50-digit result; relative differences gamma/k <= 3e-8 above k = 1e3). The extra eigenvalues of the reduced system are the constraint modes u_x - ik u with lambda = 0. Coincident principal roots occur (400/400 on A1, all of B1, B2, B3; none on A2, A3). The argument for them: a symmetric matrix is diagonalisable with a complete set of eigenvectors whatever the multiplicities. C2 holds [ANALYTIC + documented] on all backgrounds with Z != 0 (HeavyScalar).

**C1.** The principal part is diagonal in the fields (no cross second derivatives); the couplings are first-derivative terms. For the FULL first-order system (amplitudes included, so that the k = 0 and long-wave components are controlled) with constant coefficients and a real symmetric A: in Fourier space U_t = (-ikA + B)U and d|U|^2/dt = 2 Re<U, B U> <= 2 b |U|^2 with b = lambda_max((B + B^T)/2), because -ikA is anti-Hermitian. Hence gamma(k) <= b for ALL k, including k = 0. Computed b on the sets: 0.54 to 0.95 (Scalar mediator), up to 47 (HeavyScalar Z > 0 with large |g|); the bound was checked against the first-order growth rate at all 92 grid points of all 794 backgrounds: 0 violations (largest observed gamma 5.6 against b = 47 on the same family). C1 holds [ANALYTIC] where Z > 0 (HeavyScalar: energy norm positive) and for all backgrounds of the Scalar mediator. Large-k expansion for HeavyScalar: omega = +-k + delta with delta = +-g (w + q)/sqrt(Z) (upper branch) and +-g (w - q)/sqrt(Z) (lower branch): real for Z > 0 (checked numerically at k = 1e6 in 50 digits, agreement to the digits printed, max |Im| = 0), imaginary and bounded for Z < 0.

**P2a (k = 0), solved directly in 50 digits.** Scalar mediator: det K(omega, 0) = omega^4 (M^2 + g_phi^2 q^2 + g_psi^2 r^2 - omega^2): ZERO MODE (omega = 0 with multiplicity 4, two a + b t pairs) and omega^2 > 0: real on all backgrounds. HeavyScalar: omega^2 [Z (omega^2 - M^2) - 4 g^2 w^2] = 0, ZERO MODE and omega^2 = M^2 + 4 g^2 w^2/Z > 0 for Z > 0. The k = 0 check passes on all sets with Z > 0 and fails for some Z < 0 backgrounds.

## What the failures are (post-run analysis, not a registered test)
In the limit k -> 0 the leading term of det is eps F(c), with F the local polynomial of the B4 type: F = Aa Ab - g_phi^2 (w - q c)^2 Ab - g_psi^2 (v - r c)^2 Aa (Scalar mediator); F = Z(1 - c^2) - 4 g^2 (w c + q)^2 (HeavyScalar). On all 740 backgrounds of the sets A1, A2, A3, B1 the outcome FAIL-UNSTABLE occurs exactly when F has complex roots (740 of 740 agree; `t3fund_stage1_ir_equivalence.py`). For HeavyScalar the condition is 1 + 6 g^2 (w^2 - q^2)/M^2 < 0 (200 of 200 agree): the effective theory P(X) = X/2 + g^2 X^2/(2 M^2) loses hyperbolicity (P_X + 2 X P_XX < 0) for spacelike gradients X < -M^2/(6 g^2), while Z > 0 only needs X > -M^2/(2 g^2). So on these sets the instability is the long-wavelength gradient instability of the low-energy theory itself, i.e. of the B4-type local polynomial; the UV completion adds no instability of its own, and T3-fund (C3) on these sets reproduces the T2 reality condition of the local polynomial. This is a statement about the sampled sets only.

## Registered prediction that was wrong
Before the run I predicted that for HeavyScalar with Z > 0 there would be no complex root. This was derived from the large-k expansion only and is false at small k: 14 of 200 backgrounds fail, all with 1 + 6 g^2 X < 0. The prediction is recorded as falsified, no criterion changed.
